## 🛠️ Development Setup

### Prerequisites
- Node.js v20+
- npm v9+

### Installation
```bash
# Clone the repository
npm install

# Start development server
npm run dev
```

### Build for Production
```bash
# Generate production build
npm run build

# Run production server
npm start
```

## 🌐 Deployment

Deploy to Netlify with zero configuration:
1. Connect your GitHub repository to Netlify
2. Netlify automatically detects the `netlify.toml` configuration
3. Built-in redirects prevent 404 errors
4. Automatic cache invalidation for optimal performance
